BankSystem. Go-приложение для управления банковскими операциями (пользователи, счета, транзакции).

Стэк: Golang, RESTfull api, стандартный логгер Golang

Фуникцональность: Регистрация пользователя, аутентификация, получение данных о счете пользователя, созданние нового счета, получение списка счетов пользователя, получение данных о счете, удаление счета, перевод средств между счетами, просмотр истории транзакций

Регистраниця нового пользователя - sh curl -X POST http://localhost:8080/users \ -H "Content-Type: application/json" \ -d '{"username":"testuser", "password":"qwerty", "email":"test@example.com"}'
